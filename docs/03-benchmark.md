# 03 · 本地检索基线

运行 `make bench` 获取当前提交的完整表格。评估集为 `datasets/rag_eval_98.json` 的 98 条仓库文档问答；语料来自各题的 `sourceDoc` 指向的公开文件。使用 HashEmbedder 词法向量，K=3，命中指前三条包含标注来源文件；MRR 使用首次命中的倒数排名。

此基线用于比较切分策略，不测答案正确性、声明级忠实度、真实模型效果或业务指标。仓库源码和文档本身属于检索语料，任何修改都可能改变结果，因此不在文档中固化会漂移的数值；发布报告时应同时固定 Git 提交、数据集哈希和运行环境。

本仓库目前没有自动归因、优化候选、复测发布的实测提升曲线。
